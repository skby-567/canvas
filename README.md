# Canvas 画布

一个单文件、零依赖的无限画布。把图片、视频、音乐、快捷方式拖进去，双击就能预览播放。

没有后端，没有登录，没有账号。你的文件不离开你的浏览器。

## 在线使用

- GitHub Pages：<https://skby-567.github.io/canvas/>
- Cloudflare Pages：<https://canvas-canvas.pages.dev/>

两个地址内容一致，随便挑一个。想本地跑就直接双击 `index.html`。

## 能做什么

### 画布

- 无限画布，滚轮缩放、空格或拖动平移
- 多选、框选、对齐参考线
- 缩放比例实时显示，一键回到 100%

### 放进来的东西

- **图片**：拖进来即显示，双击放大看
- **视频 / 音频**：双击播放，带播放控件
- **应用快捷方式**：自动提取图标，点击直接唤起本机应用
- **网址**：收藏成卡片，点开就在新标签打开
- **录音**：直接用麦克风录一段留在画布上

### 编辑

- 富文本编辑：标题、列表、行内代码、代码块
- AI 建议以红绿差异呈现，可以单条接受或拒绝
- 版本历史：每次接受建议都会生成快照，随时回滚

## 数据存在哪

全部在浏览器本地。

- **IndexedDB**：画布上所有元素的位置、类型、内容
- **不联网**：整份文件不会发出任何网络请求（除了 W3C 命名空间声明）

换浏览器、清缓存、换设备，数据都不会跟着走。这是有意为之——也意味着别把唯一一份重要东西只放在这里。

## 技术说明

整个应用是**一个 HTML 文件**，样式和脚本全部内联，约 1 MB。

- 无构建步骤，无依赖，断网可用
- 深色 / 浅色主题跟随系统
- 移动端适配，支持触控手势

## 兼容性

Chrome / Edge / Safari / Firefox 近两年版本。需要 IndexedDB 和 Canvas 2D。
